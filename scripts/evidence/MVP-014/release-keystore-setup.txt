# MVP-014 Release 签名配置说明

## 1. 生成 release keystore（一次性，本地生成，不入库）

JDK 路径：D:\Android Studio\jbr\bin\keytool.exe

命令：
keytool -genkeypair -v -storetype PKCS12 \
  -keystore apps/mobile/android/app/release.keystore \
  -alias clothes-release \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -storepass <STOREPASS> \
  -dname "CN=Clothes App, OU=Mobile, O=Clothes, L=Shanghai, ST=Shanghai, C=CN"

说明：
- PKCS12 格式，storepass 即 keypass（PKCS12 不支持分开）。
- 有效期 10000 天（远超 P0 发布周期）。
- RSA 2048 位。
- 生成结果：apps/mobile/android/app/release.keystore（gitignored）。

## 2. 凭证文件（gitignored）

apps/mobile/android/keystore.properties（不入库，密码由本地保管）：
  releaseStoreFile=app/release.keystore
  releaseStorePassword=<STOREPASS>
  releaseKeyAlias=clothes-release
  releaseKeyPassword=<STOREPASS>

## 3. build.gradle 配置（apps/mobile/android/app/build.gradle）

signingConfigs.releaseSigning：
  - 读取 rootProject.file('keystore.properties')；
  - 存在则用 release.keystore 签名；
  - 缺失则回退 debug.keystore 并打印警告（仅限本地开发，不得用于正式发布）。

buildTypes.release.signingConfig = signingConfigs.releaseSigning
（不再复用 debug.keystore，满足「清理调试密钥」验收点）

## 4. .gitignore（apps/mobile/android/.gitignore）追加

app/release.keystore
keystore.properties

## 5. 可复现构建命令

Debug：
  cd apps/mobile/android
  set ANDROID_HOME=C:\Users\Admin\AppData\Local\Android\Sdk
  set JAVA_HOME=D:\Android Studio\jbr
  .\gradlew.bat assembleDebug

Release：
  cd apps/mobile/android
  set ANDROID_HOME=C:\Users\Admin\AppData\Local\Android\Sdk
  set JAVA_HOME=D:\Android Studio\jbr
  .\gradlew.bat assembleRelease
