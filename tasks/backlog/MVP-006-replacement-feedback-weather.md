# MVP-006：只换一件、换一套、天气降级和反馈闭环

## 用户价值

推荐不满意时用户可以保留喜欢的部分，只换一个槽位或整套重来；天气不可用也不阻塞出门决定。

## 场景与流程

TDY-03 固定其余槽位只换一件 / TDY-04 换一套并说明跳过原因 / TDY-05 选择稳妥、新鲜、主角、赶时间模式 / TDY-08 定位失败时手选城市或无天气继续。

## 必须完成

- 只换一件固定其他衣物，仅显示同槽、可用且满足硬约束的候选。
- 换一套避免立即重复已跳过组合，可保留用户锁定的主角单品。
- 反馈记录接受、替换槽位、替换前后、跳过原因和推荐模式。
- 首选和风天气适配器，缓存城市坐标、请求时间和天气窗口；提供可替换接口。
- 定位只在用户触发时申请前台权限；拒绝后可手选城市、仅本次使用或无天气。
- 天气过期、超时、无网时明确使用缓存或无天气规则，不伪造实时天气。

## 不做

- 不请求后台定位，不把天气设为首轮激活前提。
- 不做机器学习训练或云端个性化。

## 状态与失败恢复

- 候选耗尽时说明原因并允许解除锁定。
- 网络失败不清空当前搭配；反馈保存失败可重试且不重复。
- 城市和天气缓存删除后仍能进入无天气模式。

## 验收标准

- 替换一个槽位后其余衣物 ID 完全不变。
- 连续换一套不会在可选空间充足时立即返回同一套。
- 飞行模式下可用缓存；无缓存时仍能推荐并显示无天气状态。
- 反馈会改变后续规则权重，但硬约束优先级不被覆盖。

## 测试与证据

- 测试锁定槽位、候选耗尽、重复抑制、缓存新鲜/过期、拒绝定位、离线和反馈幂等。
- 反向验证：返回格式错误的天气响应，证明适配器拒绝并降级而不是显示错误温度。
- 保存 TDY-03、TDY-04、TDY-05、TDY-08 真机截图与一次离线录屏。
