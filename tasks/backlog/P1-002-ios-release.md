# P1-002：在 iPhone 上交付同等本地优先闭环

## 用户价值

iPhone 用户获得与 Android 一致的数据安全和核心闭环，抠图与 Android 共用同一分割 API。

## 场景与流程

在真实 iPhone 上重复 MVP-014 全链路，重点验证相册受限权限、抠图 API 断网降级、后台中断、文件导入导出、日历和升级迁移。

## 必须完成

- 使用 Expo Development Build 和可复现 iOS 构建；记录最低系统版本。
- 抠图复用与 Android 相同的 `RemoteSegmentationEngine`（分割 API），输出统一蒙版合约。
- 验证有限相册权限、iCloud 未下载资产、系统终止后台任务和存储压力。
- 保持与 Android 相同数据库、导出格式、推荐理由和画布坐标语义。
- 在真实 iPhone 安装、启动、升级并捕获崩溃日志。

## 不做

- 不为 iOS 单独发明产品流程，不依赖仅模拟器通过。
- 未经授权不提交 App Store。

## 状态与失败恢复

- 没有 Mac/Xcode/真机或签名能力时保持 `BLOCKED`，先完成平台无关测试。
- API 失败或断网时任务排队、可跳过，不允许伪造蒙版。

## 验收标准

- 真实 iPhone 完成与 MVP-014 相同的断网闭环和导出恢复。
- iOS 与 Android 抠图输出格式一致；蒙版可跨平台复用。
- Android 创建的导出包可在 iOS 恢复，反向亦然。

## 测试与证据

- 提交 iPhone 型号、系统、构建、安装、性能、跨平台 round-trip 和页面截图。
- 反向验证：强制 API 失败/断网，证明任务可排队/跳过且用户数据不丢。

## 依赖与优先级

优先级 P1，依赖 MVP-014；若要同时含云同步，另依赖 P1-001。
