# MVP-014：交付可安装、离线可靠的 Android P0

## 用户价值

用户拿到的不是开发演示，而是在真实 Android 上可安装、可重启、断网可用且不会丢照片的完整 P0。

## 场景与流程

全新安装 → 12 件激活 → 批量抠图/修边 → 今日推荐/替换/记录 → 衣橱/造型/计划/旅行/洞察/购物 → 导出恢复 → 断网重跑 → 升级安装保留数据。

## 必须完成

- 冻结版本号、应用 ID、迁移版本和可复现 Release/Debug 构建说明。
- 清理开发占位、假数据入口、调试密钥、无用权限和生产日志敏感信息。
- 检查冷启动、300 件衣橱、连续 12 张抠图、画布、导出恢复的性能与内存。
- 完成 360×800、390×844、430×932、1.3×字体、深浅系统设置和 TalkBack 检查。
- 验证断网核心闭环、进程被杀恢复、磁盘空间不足、权限撤回和数据库迁移。
- 生成 APK，使用 `aapt`/等价工具核对包名版本，ADB 安装、启动并读取崩溃日志。

## 不做

- 不上传应用商店、不创建生产后端、不把 P1 混入 P0。
- 不为减包删除原图保护、手修或恢复能力。

## 状态与失败恢复

- 发现 P0 回归时回到责任卡修复并重跑整条冒烟，不在本卡用特判掩盖。
- 无真机、签名或真实样本时保持 `BLOCKED`，不能用模拟器宣称发布完成。

## 验收标准

- 一台中端真实 Android 从全新安装完成完整闭环；杀进程和重启后数据一致。
- 飞行模式下除天气刷新外所有核心功能可用。
- 自动测试全绿、skip/todo 为 0；无 P0 崩溃、数据丢失或原图覆盖。
- Debug APK 可安装启动，包名/版本正确；升级安装保留旧数据并完成迁移。
- 关键页面与方向 3 在三种尺寸和字体缩放下无裁切、乱码或不可点击操作。

## 测试与证据

- 提交版本清单、质量命令、端到端输出、性能表、APK 元数据、ADB 安装/启动日志和截图索引。
- 反向验证：用旧 schema 安装包制造一次迁移失败，证明升级阻止破坏并保留回滚；修复后升级成功。
- 对 29 个已有独立设计页面建立实现截图对照；59 页未单独出图页面按规格验收。

## 依赖与优先级

优先级 P0，依赖 MVP-000 至 MVP-011（MVP-012/013 于 2026-08-02 用户决策降级 P1，不再为 P0 前置）。验收闭环「导出恢复」部分随 MVP-013 移出 P0；本卡不再验导出恢复，其余验收标准不变。
