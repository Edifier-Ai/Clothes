# MVP-011：用真实穿着记录生成可信衣橱洞察

## 用户价值

用户能看到哪些衣物被盘活、哪些长期闲置、成本/次如何变化，而不是只看到漂亮但不可解释的图表。

## 场景与流程

STA-01 总览 → STA-02 久未穿 → STA-03 成本/次 → STA-04 月度盘活报告 → 从洞察进入单品或创建造型。

## 必须完成

- 指标统一来自 SQLite 穿着事实：穿着天数、盘活单品、重复率、久未穿和成本/次。
- 每个指标定义窗口、分母、时区、归档处理和缺失价格处理。
- 久未穿支持 30/60/90 天；新录入未穿与长期未穿分开说明。
- 成本/次 = 有效购买价 / 有效穿着次数；0 次不显示伪造数值。
- 月度报告可生成脱敏分享图，不含原图路径、备注、价格或定位，除非用户主动选择。

## 不做

- 不做虚构“减少购买金额”，只能明确标为估算并展示口径。
- 不上传分析事件，不做社交排行。

## 状态与失败恢复

- 数据不足时显示学习期和如何产生数据。
- 时区变化、删除/恢复穿着记录后重新聚合。
- 分享生成失败不影响本地报告。

## 验收标准

- 固定夹具的所有指标能手工复算，页面口径与代码一致。
- 编辑或删除一条穿着记录后相关指标同步更新。
- 归档衣物保留历史贡献，但默认不进入当前可穿库存。
- 脱敏分享产物不包含受保护字段。

## 测试与证据

- 使用固定日期和金额夹具测试全部指标、边界、时区和数据不足状态。
- 对关键 SQL/聚合做快照或等价结果验证。
- 反向验证：注入一件 0 次、无价格衣物，证明不出现除零、NaN 或虚假成本。
- 保存 STA-01 至 STA-04 真机截图。

## 依赖与优先级

优先级 P0，依赖 MVP-010 与已有穿着记录。
