# MVP-013：隐私开关、完整导出和可验证恢复

## 用户价值

用户清楚知道照片在哪里处理，能逐项关闭网络能力，并把全部衣橱带走、删除或在新安装中恢复。

## 场景与流程

SET-01 设置 → SET-05 AI 与照片隐私 → SET-06 创建导出包 → 系统文件保存 → 清空测试安装 → 导入恢复；SET-07 只展示权益边界，SET-08 在无账号 P0 中用于本地数据删除说明。

## 必须完成

- 设置分别控制抠图 API 照片上传授权、天气网络和可选遥测；P0 默认无遥测，抠图上传需用户明确开启。
- 导出包含版本清单、SQLite/结构化 JSON、原图、蒙版、派生图说明、造型和记录校验值。
- 导出采用临时目录和原子完成标记；失败包不得显示为成功。
- 导入先验证版本、路径穿越、校验值、可用空间和重复 ID，再事务化恢复。
- 支持“合并”和“替换到空安装”；替换前必须自动生成回滚点。
- 本地全部删除需要二次确认；删除后扫描数据库和私有资产目录。

## 不做

- 不实现账号、云同步或虚假 Pro 购买。
- 不把数据库密钥、天气凭证或 SecureStore 内容写入导出包。

## 状态与失败恢复

- 导出中断清理临时文件，原数据不受影响。
- 导入失败恢复导入前状态，并保留错误报告。
- 旧版本包只能通过显式迁移，不允许忽略未知字段继续破坏数据。

## 验收标准

- 包含 12 件衣物、蒙版、3 套造型、计划和穿着记录的安装可完整导出。
- 在清空后的同版本 App 导入，记录数、文件哈希、画布几何和统计结果一致。
- 篡改一个文件后导入必须拒绝；恶意相对路径不能写出私有恢复目录。
- 全部删除后数据库业务记录和对应私有文件均不存在。

## 测试与证据

- 自动化 round-trip、损坏包、空间不足、重复 ID、旧版本、路径穿越和删除测试。
- 记录导出前后实体计数、哈希清单和恢复截图。
- 反向验证：修改包内一张蒙版，证明校验失败且原安装无变化；还原后恢复成功。
- 保存 SET-01、SET-05、SET-06、SET-08 真机截图。

## 依赖与优先级

优先级 P0，依赖 MVP-012。
