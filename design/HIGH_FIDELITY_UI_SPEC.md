# 智能衣橱 App 高保真界面交付规范

版本：V1.0  
日期：2026-07-27  
目标画布：390 × 844，移动端 App 内容区  
目标平台：iOS + Android  
语言：简体中文

## 1. 设计目标

把产品方案中的完整闭环转化为一套可用于产品评审、开发对齐和后续原型实现的高保真 UI：

`渐进式录入 → 保真抠图 → 今日推荐 → 搭配编辑 → 日历/旅行 → 穿着统计 → 购物守门 → 同步/隐私`

第一原则不是展示最多功能，而是让用户：

1. 首次使用 10 分钟内从 12 件真实衣服获得首组搭配。
2. 日常 30 秒内决定“今天穿什么”。
3. 始终知道推荐为什么成立，并能只换一件。
4. 随时离线使用、导出和删除数据。

## 3. 全局视觉与交互约束

- 单张图只出现一个页面或一个明确的全屏状态。
- 不出现手机外框、刘海、灵动岛、系统状态栏、时钟、信号、电池、Home Indicator、浏览器框或设备阴影。
- 正文字号按 14–16 px 的真实产品基线设计，点击目标不小于 44 × 44。
- 主导航固定为四项：`今天 / 衣橱 / 造型 / 计划`。
- 图标保持同一套细线风格；不使用 Emoji、ASCII 或临时占位符。
- 衣物使用真实、清晰、无人物的棚拍抠图；不得生成不存在的品牌标志。
- 原图、抠图和修边页面必须明确传达“不会修改真实衣物”。
- 每页只有一个主操作；次要动作降低视觉权重。
- 同一页面不堆叠多层卡片，不用玻璃拟态，不用无意义渐变。
- 日期以 2026-07-27 为锚点；周视图、日历和相对时间必须与此一致。
- 页面内可见中文需可读、语义正确；严重乱码、重复导航、裁切或错误状态均需重生成。
